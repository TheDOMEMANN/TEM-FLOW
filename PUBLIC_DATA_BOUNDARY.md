# Public data boundary

This dated TEM-FLOW 1.0.0 source package retains public topology, coordinate reconciliation, OD quantities, CPC functionality and file-import slots. Public_OD_CPC_inputs in the user package (Public_OD_CPC_inputs in the journal code archive) contains the separately supplied public evidence ledgers. Their six contaminant records retain identity and provenance but have numeric chemistry values, limits and units blanked. Chemistry-derived assessments are also withheld. These historical ledgers are reference data and use a different schema from the dated-record CSV import template. No private contaminant application ledger or restricted Nigeria raw microdata is distributed. No chemistry values are needed for the computational paper.

## Brazzaville survey data

The reproduction materials include the public retail CSV and its original
documentation from CIRAD Dataverse, DOI 10.18167/DVN1/DAMXAW, version 1. Source
and derived tables retain CC BY-NC 4.0 and attribution to Ameller, Moustier,
Maba Ngouloubi and Ofouémé-Berton. The software's BSD licence does not relicense
these data. The wholesale file is supplied for provenance only, not analysed.
The 8,208 retail records describe survey-derived quantities in April and August
2022. The reporting comparison models loss of stored aggregates, retains an
exact sample total and does not imply independent measurement validation.
