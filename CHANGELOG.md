# Changelog

## 1.0.0 — initial release

- Restored predecessor road geometry and made the road cache persist through country selection and Escape.
- Reconciled node coordinates and retained fixed-size map symbols, double-click selection and mouse navigation.
- Added a curator feature dialog for adding nodes and directed routes, reviewing removal of multiple features and connected routes, and restoring removed features by date.
- Added a portable Windows launcher, editable source tree, one version source, checks and release tools.
- Preserved optional model layers, the public/private chemistry boundary and evidence provenance.
