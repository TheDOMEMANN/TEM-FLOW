# Changelog

## 1.0.0 — structural formulation revision, 1 October 2026

- Integrated sharp prospective uncertainty profiles for nested aggregate records,
  with a known total, bounded errors and an explicit missing-record budget.
- Added general calculations for crossing groups and separate intervals for
  the readings actually entered; incompatible inputs are reported explicitly.
- Added aggregate CSV/JSON input, a desktop calculation panel, CLI and API.
- Added independent linear-program, cut, integer-state and flow-expansion checks.
- Preserved the existing empirical calculations, road geometry and public CPC/OD
  data boundary. No application contaminant values are included.
- Version remains 1.0.0 at the author's request. The original v1.0.0 Git tag is
  unchanged; revision identifiers and file hashes distinguish this extension.


## 1.0.0 — initial release

- Restored predecessor road geometry and made the road cache persist through country selection and Escape.
- Reconciled node coordinates and retained fixed-size map symbols, double-click selection and mouse navigation.
- Added a curator feature dialog for adding nodes and directed routes, reviewing removal of multiple features and connected routes, and restoring removed features by date.
- Added a portable Windows launcher, editable source tree, one version source, checks and release tools.
- Preserved optional model layers, the public/private chemistry boundary and evidence provenance.
