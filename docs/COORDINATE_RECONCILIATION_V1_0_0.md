# Coordinate reconciliation for TEM-FLOW 1.0.0

The display ledger was reconciled against the ED-FLOW / Exposure Africa
predecessor source and destination coordinate registers. The applied public
ledger contains 31 auditable exact or documented same-feature matches from 88
reviewed candidate rows. The full 88-row match audit is retained only in the
editor-private package.

Lake Ziway is now represented by the predecessor register coordinate
7.9877798 N, 38.8200713 E. This is a named-feature representative used for
atlas orientation; it is not a sampling or landing coordinate. Commodity-state
children inherit that audited physical-node coordinate.

The 57 candidates without an auditable unique match were not assigned a new
geographic claim. Their deterministic country-layout proxies remain available
for diagnostics but are hidden by default in the map interface.
